테슬라 연결 검사

주차(P) 상태에서만 사용하세요. 주행 중에는 열지 마세요.

이 기기의 역할을 고르세요. 노트북은 PC, 테슬라 화면은 테슬라를 누릅니다.

차량 화면 테슬라 브라우저 능력, ICE, 사설 IP 차단, 페어링 수신을 검사합니다. 노트북 PC 페어링 코드를 만들고, 연결 경로(LAN 직접 / 중계)와 화면 공유를 검사합니다.
대기 중

사진으로 남길 요약

페어링이 되지 않았습니다. 이 칸을 휴대폰으로 찍으세요.

결과를 PC로

연결되면 전체 결과가 자동으로 PC에 전달됩니다. 화면 공유나 탭 뒤에는 이 버튼으로 최신 결과를 다시 보내세요.

1. 환경

2. WebRTC 지원

3. ICE 후보 수집

STUN만 사용합니다. 공개 TURN 서버는 넣지 않았습니다.

    4. 사설 IP 접속 검사

    노트북의 핫스팟 IP를 입력하세요. 예: 192.168.43.52. 이 페이지는 HTTPS라서 HTTP 주소는 혼합 콘텐츠로 막힐 수 있습니다. 차단 사유를 구분해 기록합니다.

    5. PC와 페어링

    노트북에 표시된 6자리 코드를 입력하세요.

    6. 화면 수신 · 터치

    영상이 보이면 화면을 탭하세요. 좌표가 PC로 전달됩니다.
